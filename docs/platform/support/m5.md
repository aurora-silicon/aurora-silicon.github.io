# M5 series feature support

<div class="support-page-nav"><a href="../m4/">← M4 series</a><a href="../a18/">A18 series →</a></div>

M5 MacBook Air `j813` is Aurora Silicon's active new-platform target. The page
records only results observed on that Air; the owned M5 and M5 Pro MacBook Pro
systems remain untested and do not inherit those results.

!!! warning "Read-only storage milestone"

    GPT discovery and Microsoft EFI loading are proven, but the current M5 path
    deliberately exposes internal storage read-only. Installing Windows to the
    internal SSD is not yet a supported workflow.
