# M2 series feature support

<div class="support-page-nav"><a href="../m1/">← M1 series</a><a href="../m3/">M3 series →</a></div>

M2 Pro MacBook Pro `j414s` is Aurora Silicon's primary and most complete Windows
target. Support shown for the Pro/Max/Ultra family is only guaranteed on the
tested M2 Pro configuration.
