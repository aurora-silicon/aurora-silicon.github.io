# M3 series feature support

<div class="support-page-nav"><a href="../m2/">← M2 series</a><a href="../m4/">M4 series →</a></div>

Aurora Silicon has an M3 Max MacBook Pro in the lab, but no M3-family Windows
bring-up has been validated yet. The complete model matrix is present so future
results have an exact destination instead of inheriting M2 support by analogy.
