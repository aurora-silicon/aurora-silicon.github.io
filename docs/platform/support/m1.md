# M1 series feature support

<div class="support-page-nav"><a href="../">← All generations</a><a href="../m2/">M2 series →</a></div>

This page tracks Aurora Silicon's Windows support for M1, M1 Pro, M1 Max and
M1 Ultra systems. The current evidence comes from the M1 Pro MacBook Pro
`j316s`; other M1 machines remain catalogued but unvalidated.

<div class="generation-summary"><span><strong>Evidence target</strong> MacBook Pro 16-inch</span><span><strong>SoC</strong> M1 Pro · T6000</span><span><strong>State</strong> Partial / earlier bring-up</span><span><strong>Lab</strong> 3 machines</span></div>
