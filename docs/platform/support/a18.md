# A18 series feature support

<div class="support-page-nav"><a href="../m5/">← M5 series</a><a href="../">All generations →</a></div>

The A18 MacBook Neo is catalogued separately because it is not an M-series Mac.
Aurora Silicon owns an 8 GB / 256 GB configuration, but platform bring-up has
not started.
