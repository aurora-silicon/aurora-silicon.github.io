# M3 Series

The generation where Apple began splitting a single marketing name across two
SoC IDs. The M3 Max ships as either `t6031` or `t6034` depending on core count,
and the M3 Ultra arrived two years after the rest of the family.

<div markdown>

## Silicon

<div class="split-table" markdown>

| M3 Pro | `t6030` |
| M3 Max, 16 CPU cores | `t6031` |
| M3 Max, 14 CPU cores | `t6034` |
| M3 Ultra | `t6032` |

sheet. `t6031` and `t6034` are separate SoC IDs, so the 14-core and 16-core
MacBook Pros are separate machines with separate device IDs.
