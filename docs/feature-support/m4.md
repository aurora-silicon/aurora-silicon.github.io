# M4 Series

are identified, but their machines are not yet published upstream.

!!! info "M4 Pro and M4 Max machines are not catalogued"

    Apple shipped M4 Pro and M4 Max machines — the 14- and 16-inch MacBook Pro,
    the Mac mini and the Mac Studio among them — but there are no upstream
    device trees for `t6040` or `t6041` yet, so their device IDs cannot be
    stated here accurately. They need to be added from a first-party source
    before this table is complete.
