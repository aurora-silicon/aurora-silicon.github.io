# M1 Series

The first generation of Apple Silicon Macs, spanning four chips and eleven
machines. The base M1 appeared in compact machines in 2020; the Pro, Max and
Ultra chips followed across 2021 and 2022.

The M1 Ultra is two M1 Max dies joined together, which is why the Mac Studio
appears twice: `j375c` and `j375d` are the same enclosure with different silicon
and therefore different device IDs.

## Support

Windows bring-up is recorded for the M1 Pro primary target, `j316s`. Boot, all cores, the internal display, keyboard and trackpad work; USB-C is partial, without hotplug or USB 3.0. Select the device ID above for the detail. The other machines still need their own results.

## Linux bring-up

The M1 Linux tree contains the main platform, storage, graphics, display, USB and wireless drivers. That is a starting point rather than a claim that every machine is ready to use. The iMac speaker route is still missing, and installation, firmware and sleep need checking on each board.

There are Touch ID reports for `j313`, `j293` and `j314s`, plus Thunderbolt and display work on the MacBook Pro. Those results belong to the builds named in the [Air](https://github.com/aurora-silicon/linux/discussions/96) and [Pro](https://github.com/aurora-silicon/linux/discussions/95) threads. They do not carry over to the other M1 machines.

These Linux notes are from **1 October 2026**. They are separate from the Windows
states above. The [support overview](overview.md#reading-a-support-state) explains
how code, hardware results and unfinished work are recorded.

    | Keyboard / touchpad | External input drivers | USB HID and Bluetooth drivers are configured; pairing and product-specific external keyboard / mouse tests are not established by the board DTS. |
    | Ethernet / SD / PCIe expansion | Per-device qualification | PCIe host support is configured. Qualify fitted controllers, adapters and link speeds independently; do not copy support from a sibling board.  |
