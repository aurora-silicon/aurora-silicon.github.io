# M1 Series

The first generation of Apple Silicon Macs, spanning four chips and eleven
machines. The base M1 appeared in compact machines in 2020; the Pro, Max and
Ultra chips followed across 2021 and 2022.

## Support

### Windows

Existing records for `j316s` list UEFI boot, Windows Boot Manager, all cores,
internal display, keyboard and trackpad as working. USB-C is partial, without
hotplug or USB 3.0. Select `j316s` and choose Windows for the feature detail.
These records do not include a test date or exact build reference.

### Linux

No Linux feature states are published in this catalog for these machines yet.
All other device/OS combinations remain **Not recorded**; no result transfers
to a sibling machine.
