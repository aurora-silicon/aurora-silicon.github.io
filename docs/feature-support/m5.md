!!! info "The Pro and Max entries are provisional"

    The upstream codename table currently lists `t6050` against both the M5 Pro
    and the M5 Max. That is almost certainly a placeholder rather than two chips
    genuinely sharing an ID — every prior generation gave the Pro and Max
    separate SoC IDs. Both rows need confirming before they can be relied on.
