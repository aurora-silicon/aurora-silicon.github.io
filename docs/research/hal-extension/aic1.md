# AIC1

Research notes on the first-generation Apple Interrupt Controller and the Windows HAL extension work around it.

!!! warning "Windows HAL notes pending"

    The Windows HAL implementation notes have not been written up.

    Until they are, the [Discord server](https://discord.gg/DXmsSSc5aY) is the
    best place to ask about this work.

## Public Linux implementation evidence

The [Aurora Linux directory](../../feature-support/linux/overview.md) links pinned AIC/platform source and board assessments. M1–M3 source integration and J700 prerequisite work are recorded in their respective product matrices. A configured Linux interrupt controller does not establish a Windows HAL implementation or qualify an unaudited board. The discussions do not supply the Windows-specific register and HAL notes still needed here.
