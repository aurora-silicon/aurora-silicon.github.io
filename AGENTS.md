# Agent and contributor rules: aurora-silicon.github.io

**Rulebook:** follow the Aurora Silicon rulebook, https://github.com/aurora-silicon/agent-guidelines/blob/main/AGENTS.md. It applies to every agent and contributor, whoever runs them. This file adds the repo specifics.

## Repo notes

- Default branch: `main`. Open pull requests against it from `feat/`, `fix/` or `wip/` branches.
- Reviews and merges: the site's designated owners in `.github/CODEOWNERS`. Never merge or deploy the site without them.
- Device support status goes only into the support data (`src/data/`), with evidence; no hand-written per-device support or install articles.
