Aurora Silicon develops Linux support for Apple Silicon Macs: the kernel, graphics drivers, and installation tools.

## Source

- [Linux kernel](https://github.com/aurora-silicon/linux)
- [Mesa graphics](https://github.com/aurora-silicon/mesa)
- [Omarchy Mac](https://github.com/aurora-silicon/omarchy-mac)

## Hardware

[Device support](/devices/) lists features by model and SoC. Reports apply to the named device and software revision. Code in a repository does not establish working hardware support.
