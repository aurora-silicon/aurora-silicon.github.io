## Aurora Linux

The Aurora Linux installer sets up the distribution of your choice: Fedora, Arch Linux or NixOS.

It has been tested on M1 and M2 Macs (including Pro, Max and Ultra), the M4 Pro MacBook Pro and the MacBook Neo. It has not been tested on other Macs yet. The [device page](/devices/) marks each Mac.
